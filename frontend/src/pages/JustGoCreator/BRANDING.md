# Just Go Creator — branding (admin console)

**Motif pass, not scrapbook recreation.** Preserve a calm Meridian-style event workspace (list, focused dashboard later). Apply Just Go color/type motifs only — do not rebuild the consumer zine UI here.

## Tokens

Defined on `.justgo-creator` in `justGoCreatorTokens.scss`:

| Token | Value | Use |
| --- | --- | --- |
| `--jg-cream` | `#FAF6EF` | Shell background |
| `--jg-ink` | `#1A1714` | Primary text |
| `--jg-accent` | `#FF4F1F` | Primary CTAs |
| `--jg-burst` | `#FF2A2A` | Optional sparse accent only |

## Wordmark

- Asset: `src/assets/pivot/just-go-wordmark-dark.svg` on cream.
- Product label in chrome: “Creator” / copy from `justGoCreatorCopy.js`.
- Do not use Atlas gradients, Meridian ClubDash logos, or `useGradient()`.

## Typography

- Headings: Instrument Sans (`--jg-font-display`).
- Eyebrows / meta: Space Mono (`--jg-font-mono`).
- Les Flos is **not** required on admin labels.

## Do not

- Tilted scrapbook cards, sticker bursts, or dense neo-brutalist chrome in tables.
- Atlas / Meridian / ClubDash / campus org copy (use `justGoCreatorCopy.js`).
